# Tài liệu AINAR

Chào mừng bạn đến với tài liệu AINAR. AINAR (Ainar Is Not an AI Router) là một cổng API thống nhất tương thích với OpenAI, định tuyến các yêu cầu đến nhiều nhà cung cấp AI.

> **Lưu ý**: Tài liệu này có thể đã lỗi thời. Vui lòng tham khảo [tài liệu tiếng Anh](../en/README.md) để có thông tin mới nhất.
