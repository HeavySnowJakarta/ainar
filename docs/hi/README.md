# AINAR प्रलेखन

AINAR प्रलेखन में आपका स्वागत है। AINAR (Ainar Is Not an AI Router) एक एकीकृत OpenAI-संगत API गेटवे है जो कई AI प्रदाताओं को अनुरोध भेजता है।

> **नोट**: यह प्रलेखन पुराना हो सकता है। नवीनतम जानकारी के लिए कृपया [अंग्रेजी प्रलेखन](../en/README.md) देखें।
