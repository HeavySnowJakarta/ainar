# Documentación de AINAR

Bienvenido a la documentación de AINAR. AINAR (Ainar Is Not an AI Router) es una pasarela API unificada compatible con OpenAI que enruta solicitudes a múltiples proveedores de IA.

> **Nota**: Esta documentación puede estar desactualizada. Consulte la [documentación en inglés](../en/README.md) para obtener la información más reciente.

## Descripción General

AINAR proporciona un único endpoint compatible con OpenAI que puede enrutar solicitudes a múltiples proveedores de IA basándose en prefijos de nombres de modelos.
