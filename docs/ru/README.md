# Документация AINAR

Добро пожаловать в документацию AINAR. AINAR (Ainar Is Not an AI Router) — это унифицированный OpenAI-совместимый API-шлюз, маршрутизирующий запросы к нескольким провайдерам ИИ.

> **Примечание**: Эта документация может быть устаревшей. Пожалуйста, обратитесь к [английской документации](../en/README.md) для получения актуальной информации.
