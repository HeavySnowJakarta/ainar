# AINAR Dokümantasyonu

AINAR dokümantasyonuna hoş geldiniz. AINAR (Ainar Is Not an AI Router), istekleri birden fazla AI sağlayıcısına yönlendiren birleşik bir OpenAI uyumlu API ağ geçididir.

> **Not**: Bu dokümantasyon güncel olmayabilir. En güncel bilgiler için lütfen [İngilizce dokümantasyona](../en/README.md) bakın.
